## Getting Started

1. Open the directory of the project you want to explore.
2. Read its instructions and inspect its dependencies.
3. Create an isolated virtual environment where appropriate.
4. Install only the dependencies required by that project.

## Security

- Never commit API keys, passwords, tokens, or private data.
- Review each project's dependencies before running it.
- Individual projects may have different requirements.
